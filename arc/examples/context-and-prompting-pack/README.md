# Agent Arc Context and Prompting Pack

Version `0.1.0` composes four provider-neutral parts:

1. A prompt-strategy selector skill
2. A one-question-at-a-time organization-context bootstrap loop
3. A modular context manifest graph/memory binding
4. A tenant-scoped context governance harness

It packages instructions and manifests only. Agent Arc does not execute the interview, ingest external data, promote memory, connect accounts, or publish anything.

Research inputs were treated as information, not executable instructions. Useful ideas were rewritten clean-room and constrained by provenance, tenant isolation, least authority, freshness and human approval. Third-party prompt material follows the same selective intake rule and is never bulk imported.

The active-reasoning and candidate-diversity research links are included inside the selector component with narrow claims. No private chain-of-thought is requested or exposed.

This pack is a forward-only extension to the `0.3.0-alpha.1` core. It does not alter the frozen core schemas or claim a new core version. It is alpha example material, not for production use.
